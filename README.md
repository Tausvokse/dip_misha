# 🚗 Parking Reservation System

Сучасний веб-додаток для бронювання паркомісць у реальному часі. Проєкт складається з клієнтської частини (React/Vite) та серверної частини (Node.js/Express/Prisma/SQLite), які спілкуються між собою через WebSockets (Socket.io) для миттєвого оновлення карти без перезавантаження сторінки.

---

## 🛠️ Що потрібно для запуску (Prerequisites)

Проєкт налаштований для максимально швидкого старту. Ніяких баз даних чи Docker встановлювати **НЕ ПОТРІБНО**. База даних (SQLite) створюється автоматично у вигляді локального файлу.

Перед тим як почати, переконайтесь, що на вашому комп'ютері встановлено:
1. **[Node.js](https://nodejs.org/en/download/)** (рекомендується версія 18 або новіша, обов'язково разом з `npm`).

---

## 🚀 Покрокова інструкція запуску

Виконайте ці кроки в терміналі (Command Prompt, PowerShell або терміналі VS Code) у папці проєкту `Misha_prog`.

### Крок 1: Встановіть залежності

Цей проєкт використовує `npm workspaces`, тому всі бібліотеки для клієнта і сервера встановлюються однією командою з кореневої папки:
```bash
npm install
```

### Крок 2: Запуск проєкту

Щоб побачити проєкт у дії, вам потрібно запустити і сервер, і клієнт. Найзручніше зробити це у **двох різних терміналах**.

**Вкладка терміналу 1 (Запуск Сервера):**
```bash
# Переконайтеся, що ви в кореневій папці проєкту
npm run server:dev
```
*Ви побачите повідомлення, що сервер запущено на `http://localhost:4000`.*

**Вкладка терміналу 2 (Запуск Фронтенду):**
```bash
# Переконайтеся, що ви в кореневій папці проєкту
npm run client:dev
```
*Ви побачите посилання. Відкрийте браузер і перейдіть за адресою:* **`http://localhost:5173`**.

## 🛑 Можливі проблеми (Troubleshooting)

- **Порт 4000 або 5173 зайнятий:** Якщо при запуску ви отримуєте помилку `EADDRINUSE`, переконайтеся, що у вас не запущені інші проєкти, які використовують ці порти.
- **Як скинути базу даних до початкового стану?** Якщо ви щось зламали під час тестування, ви завжди можете видалити файл `server/dev.db` і виконати команду `npm run server:seed` з кореневої папки, щоб згенерувати чисту базу знову.
