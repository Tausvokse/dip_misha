# Smart Parking Reservation System

Сучасний веб-додаток для бронювання паркомісць у реальному часі. Проєкт складається з клієнтської частини (React/Vite) та серверної частини (Node.js/Express/Prisma/SQLite), які спілкуються між собою через WebSockets (Socket.io) для миттєвого оновлення карти без перезавантаження сторінки.

## 🚀 Як запустити проєкт локально

Проєкт налаштований для максимально швидкого старту. Ніяких баз даних чи Docker встановлювати **НЕ ПОТРІБНО**. База даних (SQLite) створюється автоматично у вигляді локального файлу.

### 1. Вимоги
Перед тим як почати, переконайтесь, що на вашому комп'ютері встановлено:
- **[Node.js](https://nodejs.org/en/download/)** (рекомендується версія 18 або новіша, обов'язково разом з `npm`).

### 2. Встановлення та налаштування

Виконайте ці кроки в терміналі (Command Prompt, PowerShell або терміналі VS Code) відразу після клонування з GitHub:

```bash
# Перейдіть до папки сервера
cd server

# Встановіть залежності
npm install

# Згенеруйте клієнт Prisma
npm run prisma:generate

# Застосуйте міграції до бази даних
npm run prisma:migrate

# Заповніть базу даних початковими даними (створить акаунти адміна та користувача)
npm run seed

# Запустіть сервер
npm run dev
```
Сервер запуститься за адресою: `http://localhost:4000`

Відкрийте нову вкладку терміналу та виконайте:

```bash
# Перейдіть до папки клієнта
cd ../client

# Встановіть залежності
npm install

# Запустіть клієнтський застосунок
npm run dev
```
Клієнт запуститься за адресою: `http://localhost:5173`. Відкрийте це посилання у браузері.
