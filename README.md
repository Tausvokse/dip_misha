# 🚗 Parking Reservation System

Сучасний веб-додаток для бронювання паркомісць у реальному часі. Проєкт складається з клієнтської частини (React/Vite) та серверної частини (Node.js/Express/Prisma/PostgreSQL), які спілкуються між собою через WebSockets (Socket.io) для миттєвого оновлення карти без перезавантаження сторінки.

---

## 🛠️ Що потрібно для запуску (Prerequisites)

Перед тим як почати, переконайтесь, що на вашому комп'ютері встановлені:
1. **[Git](https://git-scm.com/downloads)** (для завантаження проєкту).
2. **[Node.js](https://nodejs.org/en/download/)** (рекомендується версія 18 або новіша, обов'язково разом з `npm`).
3. **[Docker Desktop](https://www.docker.com/products/docker-desktop/)** (для запуску бази даних PostgreSQL одним кліком). Переконайтеся, що Docker запущений і працює у фоновому режимі.

---

## 🚀 Покрокова інструкція запуску

Виконайте ці кроки в терміналі (Command Prompt, PowerShell або терміналі VS Code).

### Крок 1: Завантажте проєкт

Склонуйте репозиторій на свій комп'ютер та перейдіть у папку проєкту:
```bash
git clone <посилання-на-ваш-репозиторій>
cd Misha_prog
```
*(Якщо ви завантажили проєкт ZIP-архівом, просто розпакуйте його і відкрийте папку в терміналі).*

### Крок 2: Встановіть залежності

Цей проєкт використовує `npm workspaces`, тому всі бібліотеки для клієнта і сервера встановлюються однією командою з кореневої папки:
```bash
npm install
```

### Крок 3: Налаштування середовища (Environment Variables)

Додатку потрібні файли конфігурації `.env` як для сервера, так і для клієнта. 

**Для Сервера:**
Створіть файл `.env` у папці `server/` і вставте туди наступне:
```env
PORT=3000
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/parking_reservation?schema=public"
JWT_SECRET="your-super-secret-jwt-key-change-it-in-production"
JWT_EXPIRES_IN="7d"

# Налаштування вартості паркування (в гривнях)
DAY_RATE_UAH=50
NIGHT_RATE_UAH=30
NIGHT_START_HOUR=22
NIGHT_END_HOUR=6

# Скільки хвилин триває "м'яка броня" перед оплатою
RESERVATION_LOCK_MINUTES=10
```

**Для Клієнта:**
Створіть файл `.env` у папці `client/` і вставте туди наступне:
```env
VITE_API_URL=http://localhost:3000/api
VITE_SOCKET_URL=http://localhost:3000
```
*(Ви можете просто скопіювати файли `.env.example`, перейменувавши їх на `.env` у відповідних папках).*

### Крок 4: Запуск Бази Даних

Переконайтеся, що програма **Docker Desktop** відкрита. Знаходячись у кореневій папці проєкту, виконайте команду:
```bash
docker-compose up -d
```
*Ця команда завантажить PostgreSQL і запустить базу даних у фоновому режимі на порту 5432.*

### Крок 5: Ініціалізація бази (Міграції та Дані)

Тепер потрібно створити таблиці в базі даних та заповнити їх тестовими даними (паркомісцями, користувачами):
```bash
npm run server:prisma:migrate
npm run server:seed
```
*Якщо скрипт сідів (`seed`) виконався успішно, база готова до роботи!*

### Крок 6: Запуск проєкту

Щоб побачити проєкт у дії, вам потрібно запустити і сервер, і клієнт. Найзручніше зробити це у **двох різних терміналах**.

**Вкладка терміналу 1 (Запуск Сервера):**
```bash
# Переконайтеся, що ви в кореневій папці проєкту
npm run server:dev
```
*Ви побачите повідомлення, що сервер запущено на `http://localhost:3000`.*

**Вкладка терміналу 2 (Запуск Фронтенду):**
```bash
# Переконайтеся, що ви в кореневій папці проєкту
npm run client:dev
```
*Ви побачите посилання. Відкрийте браузер і перейдіть за адресою:* **`http://localhost:5173`** (або `http://127.0.0.1:5173`).

## 🛑 Можливі проблеми (Troubleshooting)

- **Помилка під час `docker-compose up`:** Переконайтеся, що Docker Desktop запущений. Якщо порт 5432 зайнятий, зупиніть інший локальний PostgreSQL.
- **Помилка підключення до бази (Prisma):** Перевірте, чи правильно вказано пароль та порт у `server/.env` (має збігатися з `docker-compose.yml`).
- **Карта не оновлюється в реальному часі:** Переконайтеся, що у `client/.env` правильна адреса `VITE_SOCKET_URL` (має вказувати на працюючий сервер, зазвичай `http://localhost:3000`).
